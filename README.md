# Synsera

**Your Money. Your Rules.**

Recurring financial intelligence platform — Stage 1 MVP frontend.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4 with Synsera design tokens
- Local/demo state for expenses (Supabase-ready auth forms)

## Run locally

```bash
cd synsera
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- Marketing: `/` · Pricing `/pricing` · Security `/security`
- Auth: `/login` · `/register` · `/reset-password` (demo — any credentials)
- App: `/app` · `/app/subscriptions` · `/app/expenses` · `/app/expenses/new`

## Brand

Synsera only — never SubGuard. Crimson `#E33240` / charcoal / white. Dark-first with light + system themes.

## Privacy

Never ask for M-PESA PIN or bank passwords. Sample dashboard data is illustrative only.
